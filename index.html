SERVER RULES

サーバー利用規約

  • 1.他人への侮辱や不快な言動は禁止。相手をリスペクトしましょう。
  • 2.荒らし行為は理由を問わず即Ban対象となります。
  • 3.Tierテスト中のりキットの使用禁止。マクロやチートも完全禁止です。Testerと受検者はお互いを尊重してください。
  • 4.その他、管理者が不適切と判断する行為は禁止。常識を守ってプレイしてください。

TIER TEST RULES

テスト規定

  • 1.TestはFirst to 4 (FT4)で行います。使用サーバーはDiscord内の test-server チャンネルをご確認ください。
  • 2.クールダウンはありませんが、1日に受けられるTestは最大2回までです。
  • 3.使用KitはLT3まではVanilla Kitであれば自由です。HT3からはDrain Kitを使用します。
  • 4.チート・マクロの使用禁止。キーボード2個使いも禁止です。
